### Do You Need a Domain for NEUROMAP?

**No, you do not need a domain to run or test NEUROMAP.**

Since NEUROMAP is designed as a personal OSINT workstation, running it locally via PHP's built-in development server bound to `127.0.0.1` (localhost) is the most secure setup. Keeping it local prevents unauthorized access to your private target parameters, generated dorks, and investigation findings.

---

### Testing NEUROMAP on Kali Linux

Open your Kali Linux terminal and execute the following sequence:

#### 1. Install Prerequisites (if not already installed)

Ensure PHP, the SQLite extension, and Composer are available:

```bash
sudo apt update
sudo apt install php php-sqlite3 sqlite3 composer -y

```

#### 2. Clone Your GitHub Repository

```bash
git clone https://github.com/bigsamtj/NEUROMAP.git
cd NEUROMAP

```

#### 3. Install Autoloading Dependencies

Run Composer to generate the PSR-4 autoload mapping for `App\`:

```bash
composer install

```

#### 4. Prepare Environment & Storage Directories

Create the local storage folders and build the SQLite database from your schema:

```bash
cp .env.example .env
mkdir -p storage/logs storage/exports storage/evidence
sqlite3 storage/neuromap.db < database/schema.sql

```

#### 5. Start the Built-in Server

Bind the server strictly to localhost pointing to the `public/` directory:

```bash
php -S 127.0.0.1:8000 -t public

```

---

### Verifying Functionality

1. Open your web browser in Kali and navigate to `[http://127.0.0.1:8000](http://127.0.0.1:8000)`.


2. Click **+ Buat Investigasi Baru** (or navigate to `/investigation/new`).
3. Fill in test target identifiers (Name, Email, Occupation, Username, Domain) and click **Generasi Query OSINT**.
4. Click the **🚀 Kirim Laporan ke Telegram Bot** link to test your Telegram API integration. Your bot will send the report straight to your Chat ID (`5301735906`).

Recapitulation of NEUROMAP Repository Components & Functions


Directory & File	Main Function in the System
app/Auth/Session.php	Manages a secure HTTP session lifecycle, HttpOnly cookie settings, and session ID regeneration to prevent session fixation.
app/Auth/Auth.php	Handles admin login credential verification using standard PHP hashing functions (password_hash & password_verify).
app/Controllers/DashboardController.php	Retrieves the list of active cases/investigations from the database to be displayed on the main dashboard page.
app/Controllers/InvestigationController.php	Processes target form inputs, saves investigation data to the database, triggers the QueryBuilder, and handles sending instant reports to Telegram.
app/Controllers/SearchController.php	Retrieves specific case details along with the generated history of search runs (search runs).
app/Services/QueryBuilder.php	The core dorking engine that reads templates from the database and replaces dynamic placeholders ({{full_name}}, {{email}}, etc.).
app/Services/TelegramService.php	Telegram Bot API integration module tasked with sending dork summaries and investigation reports instantly.
app/Providers/SearchProviderInterface.php	Standard interface for search engine provider adapters.
app/Providers/GoogleLinkProvider.php	Provider adapter that generates secure and properly encoded Google dork search URLs.
config/app.php	Stores global application configuration settings as well as the Telegram Bot Token & Chat ID.
database/schema.sql	SQLite database schema containing the tables users, cases, query_templates, search_runs, findings, along with the built-in dorks.
public/index.php	The main application entry point (Front Controller / Router) that routes HTTP requests to the appropriate controllers.
resources/views/layout.php	The main visual layout framework (HTML/CSS) featuring a Graphite & Emerald theme.
resources/views/dashboard.php	The interface view for the investigation case list and quick buttons.
resources/views/investigation_form.php	The form interface view for inputting OSINT target parameters.
storage/	Local storage folder for the SQLite database file (neuromap.db), logs, exports, and investigation evidence (ignored by Git).
